# Generated Reports

This directory is the local destination for profiling, standardisation, matching, audit and analysis reports produced by the pipeline.

Real-data CSV, JSON, XLSX and Parquet outputs are intentionally ignored by Git and must not be committed to the public repository. Some generated reports may contain aggregate results, source values, review decisions or pseudonymous record identifiers derived from third-party research data.

Only this README is intended to be version-controlled. For public demonstrations, use synthetic data under `data/sample/` and generate disposable outputs locally.
