# Synthetic Sample Data

Files in this directory are manually created fictional records for demonstrating the expected data structure and testing transformation logic.

They are **not** samples, extracts, subsets, transformations or anonymised versions of real COLFUTURO records. Names, institutions, programmes and combinations in the synthetic files are illustrative only.

Real source data belongs under `data/raw/` and generated record-level outputs under `data/processed/`; both locations are excluded from version control.
