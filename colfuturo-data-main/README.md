# Colfuturo Data

Colfuturo Data is a Laravel application for exploring records of selected applicants and beneficiaries of COLFUTURO’s Scholarship Loan Program.

## Context

COLFUTURO is a Colombian foundation that guides and funds postgraduate studies abroad through its Scholarship Loan Program. The program supports full-time, in-person study, usually between 9 and 24 months, and offers financial support of up to USD 50,000. This app turns those records into an exploration experience with filters, maps, charts, and recommendations.

## What’s included

- KPI dashboard
- top 10 rankings by countries, universities, areas, and departments
- gender comparison: total vs male vs female
- promotion / year filter
- origin map and destination map
- profile explorer
- recommender based on similarity between previous profile and intended study plan
- CSV import with support for relative or absolute paths
